# Калькулятор производства для SimCity BuildIt

Раскладывает заказы на сырьё и этапы производства с учётом того, что уже есть на складе.

## Что умеет
- Несколько заказов с названиями, составом и количеством одинаковых заказов.
- Секции с приоритетами: заказы наследуют приоритет секции, а план сортируется по ним.
- План по этапам: сначала сырьё для заводов, затем товары по порядку изготовления, с отметками и счётчиками выполнения.
- Склад достаётся заказам по порядку; при выполнении заказа склад и отметки обновляются сами.
- Поиск заказа по составу (например, «молоток 2»).
- Резервная копия данных текстом.

## Как пользоваться
1. Вкладка «Секции» — заведи секции и приоритеты (1 — самый важный).
2. Вкладка «Заказы» — создай заказ, выбери товары, нажми «Сформировать заказ».
3. Вкладка «Склад» — укажи, что уже есть.
4. Вкладка «План» — смотри, что и в каком порядке делать.

## Установка на телефон
Открой страницу в браузере и добавь на экран «Домой»: в Chrome «Установить приложение», в Safari «Поделиться → На экран “Домой”». После первого открытия работает без интернета.

## Данные и приватность
Всё хранится только в браузере на твоём устройстве, ничего не отправляется на сервер. Устройства между собой не синхронизируются: для переноса используй «Скопировать данные» и «Восстановить» на вкладке «Склад».

## Оговорка
Неофициальный инструмент, не связан с EA и Maxis. SimCity и BuildIt — товарные знаки их владельцев. Рецепты, цены и время взяты с открытой вики игры и могут отличаться от актуальных.
На данный момент реализованы товары, доступные игрокам до 38-го уровня включительно.
